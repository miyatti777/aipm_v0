## 1. 変更管理プロセス

```
変更要求発生 → 登録 → 影響分析 → 承認判定 → 実施 → 完了確認
                ↑                    │
                └── 却下 ←──────────┘
```

### 承認権限

| 影響度 | 承認者 |
|--------|--------|
| 高（スケジュール1週間以上遅延 or 予算10%以上影響） | プロジェクトスポンサー（CFO） |
| 中（スケジュール1週間以内 or 予算5〜10%影響） | PM + 経理責任者 |
| 低（軽微な設定変更等） | PM |

### ステータス定義

| ステータス | 説明 |
|-----------|------|
| **起票済** | 変更要求が登録された |
| **分析中** | 影響分析を実施中 |
| **承認待ち** | 承認者の判定待ち |
| **承認済** | 承認され、実施待ち |
| **実施中** | 変更を実施中 |
| **完了** | 変更が完了し、確認済み |
| **却下** | 変更要求が却下された |
| **保留** | 判断を保留中 |
