## 3. 電子帳簿保存法の最新動向

### 3.1 電帳法の概要

| 区分 | 内容 |
|------|------|
| **電子取引データ保存** | メール・Webで受領した請求書等の電子保存が義務化（2024年1月〜） |
| **スキャナ保存** | 紙の領収書等をスキャン保存する場合の要件 |
| **電子帳簿保存** | 会計ソフト等のデータ保存要件 |

### 3.2 スキャナ保存の要件（経費精算に関連）

| 要件 | 内容 | バクラク精算の対応 |
|------|------|-------------------|
| 入力期間 | 受領後おおむね7営業日以内（速やか要件） | スマホ撮影で即時対応可能 |
| 解像度 | 200dpi以上 | スマホカメラで充足 |
| カラー | カラー画像 | 対応 |
| タイムスタンプ | 一般財団法人認定のタイムスタンプ付与 | 標準機能で自動付与 |
| 検索要件 | 取引日・金額・取引先で検索可能 | 標準機能で対応 |
| 訂正削除の履歴 | 訂正・削除の履歴が確認できること | システムで自動管理 |
| 相互関連性 | 帳簿との相互関連が確認できること | 仕訳連携で対応 |

### 3.3 対応上の留意点

- 「速やか要件」を満たすため、従業員への即時撮影の習慣化が重要
- スキャナ保存を選択した場合、原本（紙）の廃棄が可能（一定条件下）
- 税務署への事前届出は2024年以降不要

## 4. 経費精算DXの成功事例

### 事例 1: 製造業A社（従業員500名）

| 項目 | 内容 |
|------|------|
| 導入ツール | クラウド経費精算サービス |
| 導入前の課題 | 紙申請、月末集中、経理残業月40時間 |
| 導入効果 | 申請時間70%削減、経理残業80%削減、差戻し率15%→3% |
| 成功要因 | 段階的導入（パイロット→全社）、経理部門主導、手厚いトレーニング |
| 教訓 | 全社展開前のパイロット期間で操作マニュアルを改善することが重要 |

### 事例 2: IT企業B社（従業員200名）

| 項目 | 内容 |
|------|------|
| 導入ツール | クラウド経費精算＋会計連携 |
| 導入前の課題 | リモートワーク対応不可、電帳法未対応 |
| 導入効果 | リモート対応100%、電帳法完全対応、ペーパーレス化達成 |
| 成功要因 | 情シスとの早期連携、SSO統合、Slack通知連携 |
| 教訓 | 承認者のモバイル利用促進が定着の鍵 |

### 事例 3: サービス業C社（従業員1,000名）

| 項目 | 内容 |
|------|------|
| 導入ツール | クラウド経費精算（大規模導入） |
| 導入前の課題 | 拠点間の精算フロー不統一、監査指摘 |
| 導入効果 | フロー統一化、内部統制強化、監査指摘ゼロ |
| 成功要因 | 全拠点統一ルール策定、部門チャンピオン制度、FAQの充実 |
| 教訓 | 大規模導入では「部門チャンピオン」の設置が効果的 |

### 当社への示唆

| # | 示唆 | 当プロジェクトへの適用 |
|---|------|---------------------|
| 1 | パイロット→全社の段階的導入が成功率を高める | Phase1でパイロット、Phase3で全社展開 |
| 2 | 承認者のモバイル利用が定着の鍵 | 承認者向けの重点トレーニング実施 |
| 3 | 部門チャンピオン制度が大規模展開に有効 | 各部門に推進担当者を配置 |
| 4 | マニュアル・FAQの品質が問い合わせ数に直結 | パイロット中にマニュアルをブラッシュアップ |
