## ペルソナ 1: 営業職 田中 健太（経費申請者）

### プロフィール

| 項目 | 内容 |
|------|------|
| **名前** | 田中 健太（たなか けんた） |
| **年齢** | 32歳 |
| **役職** | 営業部 主任 |
| **勤続年数** | 7年 |
| **ITリテラシー** | 中（スマホは日常的に使用、業務PCはメール・Excel中心） |
| **経費精算頻度** | 月4〜6件（交通費・接待費・出張費） |

### 行動特性

- 外回りが多く、オフィスにいる時間が限られる
- 領収書を財布に溜め込み、月末にまとめて申請する傾向
- Excelの申請書テンプレートの勘定科目に迷うことが多い
- リモートワーク日にはそもそも紙の提出ができない

### ペイン（課題）

1. 領収書をなくしてしまい、自腹になったことがある
2. 勘定科目の選び方が分からず、毎回経理に聞いている
3. 申請書作成に時間がかかり、本業の営業活動に支障
4. 精算完了まで2〜3週間かかり、立替金額が大きいと負担

### ゲイン（期待）

1. スマホで領収書を撮影するだけで申請できる
2. AIが勘定科目を自動判定してくれる
3. 移動中や外出先からでも申請できる
4. 精算サイクルが短くなり、立替負担が軽減される

## ペルソナ 2: 経理担当 佐藤 美咲（経理処理者）

### プロフィール

| 項目 | 内容 |
|------|------|
| **名前** | 佐藤 美咲（さとう みさき） |
| **年齢** | 28歳 |
| **役職** | 経理部 担当 |
| **勤続年数** | 4年 |
| **ITリテラシー** | 中〜高（会計ソフト・Excel関数を日常的に使用） |
| **経費精算処理頻度** | 月100〜150件 |

### 行動特性

- 毎月の経費精算チェックに多くの時間を費やしている
- 領収書と申請書の突合を1件ずつ手作業で行う
- 仕訳入力は会計システムに手打ちで転記
- 月末〜月初は残業が常態化している

### ペイン（課題）

1. 月末に申請が集中し、チェック作業に追われる
2. 記入ミスや添付漏れによる差戻しが多く、やり取りが増える
3. 仕訳の手入力に時間がかかり、転記ミスのリスクがある
4. 紙の領収書のファイリング・保管場所が不足している
5. 電帳法対応をどう進めればいいか分からない

### ゲイン（期待）

1. OCRによる自動読取で照合作業が大幅に削減される
2. 申請時点でバリデーションがかかり、差戻しが減る
3. 仕訳が自動生成され、会計システムへの連携が楽になる
4. 電子保存で紙のファイリングから解放される
5. 電帳法に自動で対応できる安心感

## ペルソナ 3: 部門マネージャー 鈴木 大輔（承認者）

### プロフィール

| 項目 | 内容 |
|------|------|
| **名前** | 鈴木 大輔（すずき だいすけ） |
| **年齢** | 45歳 |
| **役職** | 事業部 部長 |
| **勤続年数** | 18年 |
| **ITリテラシー** | 低〜中（メール・チャット中心、新ツール導入に慎重） |
| **経費承認頻度** | 月15〜25件（部下10名分） |

### 行動特性

- 会議や出張が多く、デスクにいる時間が少ない
- 経費承認は「後でまとめてやろう」と後回しにしがち
- 部下の予算消化状況を把握したいがデータが即座に出ない
- 新しいツールの導入には「今のままでいい」と消極的

### ペイン（課題）

1. 紙の申請書が机に溜まり、承認が遅れて部下に迷惑をかける
2. 出張中は物理的に承認ができない
3. 部門全体の経費状況がリアルタイムで分からない
4. 新システムを覚えるのが面倒

### ゲイン（期待）

1. スマホでワンタップ承認できれば移動中にも処理可能
2. 部門の経費をダッシュボードで一覧確認できる
3. 操作がシンプルであれば移行のストレスが少ない
4. 承認漏れのリマインド通知で対応忘れを防止
