## 1. 概要

### 1.1 プロダクトビジョン

バクラク精算の導入により、「全従業員がストレスなく経費を申請でき、経理部門が本来の分析業務に集中できる」状態を実現する。

### 1.2 ターゲットユーザー

| ユーザー種別 | 人数（推定） | 主な利用シーン |
|-------------|-------------|---------------|
| 経費申請者（全従業員） | （要記入）名 | 経費発生時の領収書撮影・申請 |
| 承認者（マネージャー） | （要記入）名 | 部下の経費申請の承認・差戻し |
| 経理担当者 | （要記入）名 | 申請チェック・仕訳処理・振込 |
| 管理者 | （要記入）名 | マスタ管理・レポート確認 |

## 2. 機能要件

### 2.1 経費申請機能

| # | 要件 | 優先度 | 詳細 |
|---|------|--------|------|
| F1 | 領収書OCR読取 | Must | スマホカメラで領収書を撮影し、AI-OCRで金額・日付・取引先を自動読取 |
| F2 | 経費申請作成 | Must | 読取データをベースに申請を作成。手動修正も可能 |
| F3 | 勘定科目自動判定 | Must | 取引内容から勘定科目をAIが自動提案 |
| F4 | 複数レシート一括申請 | Should | 複数の領収書をまとめて1件の申請として提出可能 |
| F5 | 交通費自動計算 | Should | 乗換検索と連携した交通費の自動計算・入力 |
| F6 | 定期区間控除 | Should | 通勤定期区間を自動で控除 |
| F7 | 下書き保存 | Must | 申請途中で下書きとして保存可能 |
| F8 | 申請履歴確認 | Must | 過去の申請一覧・ステータスの確認 |

## 4. 設定要件（導入時に決定が必要な項目）

### 4.1 承認フロー設定

| 条件 | 承認ルート | 備考 |
|------|-----------|------|
| 一般経費（〜5万円） | 直属上長 → 経理確認 | 1段階承認 |
| 一般経費（5万円〜20万円） | 直属上長 → 部門長 → 経理確認 | 2段階承認 |
| 一般経費（20万円超） | 直属上長 → 部門長 → 本部長 → 経理確認 | 3段階承認 |
| 接待費（全額） | 直属上長 → 部門長 → 経理確認 | 金額問わず2段階 |

> ※ 上記は初期案。社内規程に合わせて調整が必要
